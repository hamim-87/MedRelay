## Derived-data provenance
| artefact | provenance tag | meaning |
|---|---|---|
| canonical patients/encounters/notes | `documented_source` | copied from the source; date-only times flagged `time_imputed=True` |
| action examples | `label_tier=silver`, `label_method=rule_v1` / `synthea_template_rule` | rule-proposed, **not reviewed**; `gold` exists only for rows in `data/annotations/reviewed/*.csv` |
| obligations (chain position 0) | `extracted_rule` / `documented_source` | from rule extraction or documented orders/results |
| obligations (other chain positions), all events not copied from a source event | `simulated` | generated by `src/generate_scenarios.py` (seeded) |
| graph/stream records | inherited per record, plus `is_simulated` on the stream | |

**No cross-dataset patient linkage exists.** MTS-Dialog and ACI-Bench records are document-level pseudo-patients (`is_pseudo_patient=True`)
with *simulated* anchor dates (`created_time_precision=simulated`); the simulated follow-up layer attached to them is a generated scenario.
